# S4C Broadcast Archive Entities

## About the data

* **What?** - This dataset is the output of a research project, using machine learning techniques to identify entites in Broadcast Archive descriptions and link them to Wikidata entities. The data contains lists of each example of an entity in a given record, organised by people, places and production companies, as well as a seperate list of all unique entities identified. The data includes links to SNARC, Wikidata and the public catalogue records in Clip Cymru. For the "People & Groups" dataset the role of the person is also noted (e.g. Actor, Director, Presenter) in the for of SNARC intity ID's. &#x20;
* **Who?** - Created using Named Entity Recognition models and computational reconciliation techniques by the National Library of Wales. Data accuracy may vary.
